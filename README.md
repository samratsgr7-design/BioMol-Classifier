# Biomolecules Classifier 🧬✨

A Python + AI tool to classify Amino Acids for Biotechnology & PU-CET Biology research.

### What it does 🧪

*   Classifies amino acids as Acidic / Basic / Neutral
*   Checks Essential vs Non-Essential
*   Shows charge (+ve / -ve) and polarity
*   Detects Sulphur-containing amino acids ⚡
*   Clean, fast, and useful for lab + exams

### How to run 🚀

```bash
python biomol.py
